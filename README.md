Sunset Bay is an original open-world crime game: explore a sun-soaked coastal city on foot and by car, steal cars, outrun the Bay PD as your wanted level rises, and run a five-job story for the fixer Rico — plus taxi fares and hidden cash packages.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Move with WASD, sprint with Shift, steal a car with E, shoot with the mouse, punch with F, start a mission with Q, pause with P.
